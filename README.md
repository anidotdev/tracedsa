# TRACE

TRACE is a DSA learning app that gives you a structured path through data structures and algorithms instead of making you randomly pick problems from a huge list.

The idea is simple: learn a concept, solve the problems that build on it, and keep moving forward.

The whole curriculum is represented as a dependency graph. Topics and problems are both nodes, so the graph shows not just what you've learned, but what you need to learn next.

## What it does

- Structured DSA progression
- Topic and problem dependencies
- Problems unlock as you progress
- Progress tracking
- Lightweight XP
- Curated learning resources
- Supabase authentication and persistence
- Responsive journey graph
- Smooth horizontal scrolling with Lenis on desktop
