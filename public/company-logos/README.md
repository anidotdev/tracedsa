The normal SVG is used in light mode. The -dark.svg version is used in dark mode. Download the colored logo variant for both themes from Brandfetch. The dark version should use a light or white wordmark where the normal version uses a black wordmark.

If a dark SVG is missing, the application falls back to the normal SVG instead of leaving the logo blank.
